# 青の光：おまつりのおみせやさん！ 🛍️

2027年8月7日（土）・8日（日）の「光をさがせ！」青の光の**ゲーム単体おためし版**。屋台で人気の4つの食べ物を主役にした、30秒で遊べる短い注文ゲームです。

## 商品（今回決定）

- 🍧 かき氷
- 🍎 りんご飴
- 🍌 チョコバナナ
- ☁️ わたあめ

絵文字は今のところ仮のイラスト表現です。背景や商品画像の本採用は、スマホで試した後に検討します。本物の屋台から注文したり、代金を徴収したりする機能ではありません。

## 1日目（8月7日）「ちゅうもんをそろえよう！」

- `?day=1#blue` で直接試せます。
- お客さんの注文に商品が**1つ**登場します。
- メニュー4種類から正しい品物をタップすると1組分クリア。
- **6組**の注文を30秒以内に完成すれば勝利。
- まちがえたらライフが1つ減ります。ライフは3つです。
- 注文を1組完成すると約0.7秒で次の注文が来ます。

## 2日目（8月8日）「おみせやさんは大いそがし！」

- `?day=2#blue` で直接試せます。
- お客さんが**違う商品2つ**を注文します。
- 画面に表示された**左から右の順番どおりに**商品をタップすると、1組分完成です。
- 4組分を30秒以内にそろえると勝利。ライフは3つです。
- 間違えたらライフ1つ減り、同じ注文の最初の品物からやり直しです。
- ゲーム中は一時停止・再開ができます。

## 見た目・音・導線

- 既存ホームから「光のQRをよみとる」→デモ「**あおを試す**」→「おみせやさんであそぶ」で遊べます。直接URLからも開始できます。
- 幻想的な夜の青い背景に、提灯、屋台ののれん、4つの商品ボタン、お客さんの吹き出しを表示します。
- 画面上部に残り時間・注文数・ライフを表示し、正解にはキラキラ、完成時はお祝いメッセージを表示します。
- 青専用のMP3はまだ決まっていないため、BGMは正式採用済み**共通曲**`four_lights_of_suzuran.mp3` をそのまま使用し、赤の専用曲は使用しません。
- M PLUS Rounded 1c を含む既存のフォント指定を使います。

## おすすめのお店機能との違い

**このゲームは独立した架空の屋台です。** 既存の「おすすめのお店」は参加者が実際の夏祭りで見つけた店を投稿するページです。ゲームの4品や選択結果を「おすすめのお店」の投稿欄に書き込むことはありません。

本番の受付QR・光QR、データベース、他人のスマホとの共有、ゲームクリアで提灯が灯る連携、カメラ・GPS・写真アップロードなどは未実装です。

## テスト

- ルールは `js/blue-game-model.js` に分離。個人情報・通信・保存機能なし。
- モデルテスト `tests/blue-game.cjs`：1・2日目の目標、順番、ミスによるハート減少、時間切れ、再挑戦、一時停止など8ケース。
- ブラウザーの `tests/smoke.cjs`：スマホ幅で両日ゲームを遊び、勝利・再挑戦・一時停止・BGM・画面の崩れを確認するケースを追加。
- 今回の実装コードをPRで確認してマージした後に、Android／iPhoneで遊び心地を確認してください。

ゲーム時間・目標は `js/blue-game-model.js` の `RULES` で調整可能。1日目の赤ゲーム、2日目の赤ゲーム、採用済み画像・音源、受付スクリーンを変更しません。
