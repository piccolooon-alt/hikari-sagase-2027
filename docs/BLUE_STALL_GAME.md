# 青の光：おまつりのおみせやさん！

添付「青ゲーム_新チャット引き継ぎ一式_20261026.zip」の独立試遊版を、既存アプリの `section#blue-preview` に組み込んだ版です。起点は main `957b180f6d22203da9c98a60244a30a73644c1f4`。既存PR #11・#12 は旧版の青ゲーム／キャッシュ対策なので取り込まず、最新mainから変更します。

## 背景・人物・素材

- 固定背景はZIPの `試遊版/assets/stall.webp`（青い屋台、低く横に広がるピンクの富士山滑り台、提灯）。
- 赤い浴衣の女の子／黒い甚平の男の子／コギャルな女子中学生／大人しめな男子中学生からランダムに1人登場。同じ人物は連続しません。
- ZIPのWebP 30点をそのまま `assets/blue-game/` へ配置。背景1点＋透過素材29点、合計1,401,482 bytes。顔や服装、切り抜きは変更していません。
- 人物と注文は上側、料理の工程画像は背景の調理台へ直接表示。4択は素材画像と短い工程名を並べた半透明のボタンです。
- 大きな調理パネル・独立版の日付切替・ページ全体の雛形・Base64埋め込みは使用しません。

## 5品と作り方

| 品物 | 工程（最後の「おわたし」で提供） |
| --- | --- |
| わたあめ | 棒 → ザラメ → くるくる回す → ふわふわ完成 → おわたし |
| いちごのかき氷 | 器 → ふわふわの氷 → いちごシロップ → スプーン → おわたし |
| やきそば | めん → キャベツ → ソースで焼く → 皿に盛り付け → トッピング → おわたし |
| フランクフルト | 棒 → ウインナー → こんがり焼く → ケチャップ → おわたし |
| トルネードポテト | 棒 → じゃがいも → カラッと揚げる → お塩をふる → おわたし |

工程ごとに4択を作り直します。「棒」が正解と誤答の両方に出るような紛らわしい重複は除外します。ミスはライフが1つ減るだけで、作りかけは保持します。工程画像と小さな丸で進み具合を表示します。

## 既存アプリとの境界

- `js/app.js` の `window.HikariBlueGame.enter(day)`／`leave()`、`#blue-preview-back`、既存の履歴・画面遷移を維持。
- 共通BGM `four_lights_of_suzuran.mp3` と共通ON/OFF操作をそのまま利用。青画面のみ、音楽ボタンとヘッダーが重ならない位置を指定。
- 赤ゲーム、ホーム、QR、ヒント帳、おすすめのお店、音楽・保存処理、受付スクリーンは変更しません。新たな発見・クリア情報の保存／送信もありません。
- `index.html` は青sectionと読み込み更新識別子だけを変更。`css/app.css` は青用ブロックだけを変更。

## 確認方法

```sh
node tests/blue-game.cjs
node tests/red-game.cjs
node tests/smoke.cjs
node tests/red-collision-visual.cjs
```

ブラウザーテストにはPlaywrightと対応ブラウザーが必要です。既存の `CHROMIUM_PATH` で実行ブラウザーを指定できます。

青のブラウザーテストは320×568／360×800／390×844／430×932の両日、画像読み込み、タップ範囲、5品全工程、4人の登場、連続重複なし、クリア、ミス、時間切れ、中断・再開・非表示時停止、切替待ちの停止、リトライ、戻る・履歴、共通BGMを対象にします。既存の共通画面・赤ゲームの回帰テストも維持しています。ブラウザーのモバイル設定はスマートフォン実機そのものではありません。

2026年10月26日の実行結果：Chromium 153.0.8010.0でブラウザー27項目と赤の描画・衝突4項目が成功。青モデル12項目、赤モデル16項目も成功しました。30点のWebPがZIPとバイト一致し、人物・料理の29点は透過アルファを持つこと、青以外のHTMLと既存CSS部分が元のmainと一致することも確認済みです。320pxと430pxを含むブラウザー画像を目視確認しました。Safari・スマートフォン実機での確認は未実施です。
