# 青の光：おまつりのおみせやさん！ — 作って渡す版

2026年のお祭りの赤ゲームで好評だった「注文を受ける→材料から作る→仕上げて渡す」操作の楽しさを参考にした、2027年・青い光の操作確認版です。**デザインと正式イラストは未決定**。2026年の元ゲームと2027年の赤ゲームは変更しません。

## お客さん
女の子／男の子／中学生の女の子／中学生の男の子／おばあさんの5人からランダムに登場します。同じお客さんが連続しない設定です。いまは仮の絵文字で表示します。

## 4品と作り方（全品最後に「おわたし」）
- 🍧 **かき氷**：うつわ → ふわふわの氷 → シロップ → スプーン → おわたし
- 🍎 **りんご飴**：りんご → ぼう → あめをつける → つつむ → おわたし
- 🍌 **チョコバナナ**：バナナ → ぼう → チョコをかける → トッピング → おわたし
- ☁️ **わたあめ**：ぼう → ザラメ → くるくるまわす → つつむ → おわたし

各工程で画面に4つの材料・道具の選択肢が出ます。順にタップすると、作った工程が作業台に表示されます。間違えるとライフ1つ減りますが、作りかけの商品はリセットされません。

## 両日の違い
- **1日目（8月7日）**：1人につき1品の注文。3人に渡せばクリア。制限時間45秒、ライフ3。
- **2日目（8月8日）**：1人につき2品の注文。2人に渡せばクリア。制限時間65秒、ライフ3。注文の左の品物から作ります。

作る工程が増えたので、時間と注文人数は従来のタップ版から仮調整しています。実際に遊んでから難易度を最終決定します。
