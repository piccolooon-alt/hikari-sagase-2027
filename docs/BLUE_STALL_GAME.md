# 青の光：おまつりのおみせやさん！ — 画像入り2027版

## 確定したデザインと操作
2026年のお祭りで遊んだ「注文を受ける→材料から作る→仕上げて渡す」ミニゲームを2027年に発展させました。利用者が選んだ縦長の青い屋台の**内側から見た風景**（奥に水袋公園のピンク色の富士山滑り台）、切り抜いた4人のキャラクター、料理5品の調理素材を採用しています。

巨大な青い調理パネルはやめ、**屋台の調理台の上に作りかけの料理を表示**。四つの材料候補だけを画面下に置くことで、背景の提灯や滑り台も見える構成にしました。周辺の発光・切り抜きの余白は素材制作段階で調整済みです。

## お客さん（ランダム4人）
- 赤い浴衣の女の子
- 黒い甚平の男の子
- コギャルな女子中学生
- 大人しめな男子中学生

同じ人が連続では登場しない設定です。イラストはそれぞれ透明背景の軽量WebPです。

## 料理5品と手順
| 食べ物 | 材料からできあがりまで |
| --- | --- |
| わたあめ | 棒 → ザラメ → くるくる回す → ふわふわ完成 → お渡し |
| いちごのかき氷 | 器 → ふわふわの氷 → いちごのシロップ → スプーン → お渡し |
| やきそば | めん → キャベツ → ソースで焼く → 皿に盛り付け → トッピング → お渡し |
| フランクフルト | 棒 → ウインナー → こんがり焼く → ケチャップ → お渡し |
| トルネードポテト | 棒 → じゃがいも → カラッと揚げる → お塩をふる → お渡し |

各工程で4つの候補がランダムに並びます。合っている材料や道具をタップすると作りかけの料理が変化します。間違えるとライフが1つ減りますが、調理中の工程は保持されます。

## GitHub Pagesへの組み込み
- 親アプリのURL：`index.html?day=1#blue` または `index.html?day=2#blue`
- 青ゲーム本体：`blue-game/index.html?day=1`／`blue-game/index.html?day=2`
- 本体は**32個のWebP画像をHTML内に直接埋め込んだ単一ファイル**です。外部の画像ホスト・Googleドライブ・Canva共有リンクは不要です。
- `js/blue-game.js` が iframe を読み込み、親アプリの共通BGMを維持。青ゲームの「もどる」から親アプリの光発見画面／ホームへ戻れます。
- 旧 `js/blue-game-model.js` は従来試作のルールテスト用に残していますが、画像入りゲーム本体の処理には使用しません。
- 2027年の赤ヨーヨーよけ、共通画面、保存データ、2026年の元ゲームは変更しません。
- 受付QR・おすすめのお店投稿・中央スクリーンの集計との連携は今後の課題です。
