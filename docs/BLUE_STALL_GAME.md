# 青の光：おまつりのおみせやさん！ 🛍️

2027年8月7日（土）・8日（日）の「光をさがせ！」青の光の**ゲーム単体おためし版**。屋台で人気の4つの食べ物を主役にした、30秒で遊べる短い注文ゲームです。

## 商品（今回決定）

- 🍧 かき氷
- 🍎 りんご飴
- 🍌 チョコバナナ
- ☁️ わたあめ

絵文字は今のところ仮のイラスト表現です。背景や商品画像の本採用は、スマホで試した後に検討します。本物の屋台から注文したり、代金を徴収したりする機能ではありません。

## 1日目（8月7日）「ちゅうもんをそろえよう！」

- `?day=1#blue` で直接試せます。
- お客さんの注文に商品が**1つ**登場します。
- メニュー4種類から正しい品物をタップして、おさらの「おわたし！」ボタンを押すと1組分クリア。
- **6組**の注文を30秒以内に完成すれば勝利。
- まちがえたらライフが1つ減ります。ライフは3つです。
- 「おわたし！」を押すと提灯が1つ灯り、約0.7秒で次のお客さんが来ます。

## 2日目（8月8日）「おみせやさんは大いそがし！」

- `?day=2#blue` で直接試せます。
- お客さんが**違う商品2つ**を注文します。
- 画面に表示された**左から右の順番どおりに**商品をタップして、おさらに2品をそろえ、最後に「おわたし！」を押すと1組分完成です。
- 4組分を30秒以内にそろえると勝利。ライフは3つです。
- 間違えたらライフ1つ減り、同じ注文の最初の品物からやり直しです。
- ゲーム中は一時停止・再開ができます。

## 2026年の赤ゲームを参考にした改修（2026年10月25日）

参考元：<https://piccolooon-alt.github.io/suzuran-summer-game/>（2026年の赤・屋台スピードパズル）。

2026年版の「お客さんから注文 → 選ぶ／作る → 完成した料理を目で確かめる → 提供！ → 提灯点灯」「お客さんが入れ替わる」「コンボと効果音」の楽しさを、**2027年の青色に合わせた新しい見た目**として取り入れました。2026年のリポジトリには一切変更していません。

- お客さん：子どもやおばあちゃんなど5種類。次のお客さんに変わると表情（絵文字）とひとことが入れ替わります。料理との固定ペアにはなりません。
- おさら：正しい商品をタップするたびに、おさらへポンっと載ります。2日目は2品順番にそろえていきます。
- おわたし：商品が揃うと金色に光る「おわたし！」が押せます。**押すまでは注文の完成数を増やしません**。
- 提灯：1組におわたしするたびに、上部の提灯が1つずつ光ります（このゲーム内だけの表示）。
- コンボ：連続正解数が増えます。間違えると0に戻ります。クリア画面に最高コンボも表示します。
- 効果音：商品を選んだとき、完成したとき、まちがえたとき、おわたし時に小さな音。既存のBGMが再生中のときだけ鳴り、音を消す操作と連動します。
- 軽量：素材を外部から読み込まず、DOMとCSSの小さな演出のみ。動きを減らす端末設定にも対応します。

**決定済みのルールは維持**：1日目＝1品×6組、2日目＝順番指定の2品×4組、30秒、3ライフ、4つの食べ物。赤ゲーム・共通画面・BGM・現地QR/受付連携には変更を入れません。

イラストはまだ仮の絵文字です。正式な屋台背景・料理・お客さんのイラストは、スマホで試した見た目を見ながら決められます。

## 見た目・音・導線

- 既存ホームから「光のQRをよみとる」→デモ「**あおを試す**」→「おみせやさんであそぶ」で遊べます。直接URLからも開始できます。
- 幻想的な夜の青い背景に、提灯、屋台ののれん、4つの商品ボタン、お客さんの吹き出しを表示します。
- 画面上部に残り時間・注文数・ライフを表示し、正解にはキラキラ、完成時はお祝いメッセージを表示します。
- 青専用のMP3はまだ決まっていないため、BGMは正式採用済み**共通曲**`four_lights_of_suzuran.mp3` をそのまま使用し、赤の専用曲は使用しません。
- M PLUS Rounded 1c を含む既存のフォント指定を使います。

## おすすめのお店機能との違い

**このゲームは独立した架空の屋台です。** 既存の「おすすめのお店」は参加者が実際の夏祭りで見つけた店を投稿するページです。ゲームの4品や選択結果を「おすすめのお店」の投稿欄に書き込むことはありません。

本番の受付QR・光QR、データベース、他人のスマホとの共有、ゲームクリアで提灯が灯る連携、カメラ・GPS・写真アップロードなどは未実装です。

## テスト

- ルールは `js/blue-game-model.js` に分離。個人情報・通信・保存機能なし。
- モデルテスト `tests/blue-game.cjs`：1・2日目の目標、商品をそろえてから渡す操作、客の切り替え、コンボ、提灯進捗、ミスによるハート減少、時間切れ、再挑戦、一時停止など9ケース。
- ブラウザーの `tests/smoke.cjs`：スマホ幅で両日ゲームを遊び、商品をそろえる→渡す→提灯が灯る、勝利・再挑戦・一時停止・BGM・画面の崩れを確認するケースを追加。
- 今回の実装コードをPRで確認してマージした後に、Android／iPhoneで遊び心地を確認してください。

ゲーム時間・目標は `js/blue-game-model.js` の `RULES` で調整可能。1日目の赤ゲーム、2日目の赤ゲーム、採用済み画像・音源、受付スクリーンを変更しません。
