## ゲームの挙動
1. 6種類（red / blue / yellow / green / purple / pink）のヨーヨーを、ZIP内の個別PNGから読み込み、ランダムな順番で出現させる。画像はロープ部分や模様まで自然に表示し、不要な枠・背景・四角い余白を見せない。
2. ヨーヨーは上・左・右・斜めなど**様々な方向**から画面内へ飛んできて、速度と角度に適度なばらつきを持たせる。単に上から垂直落下するだけにしない。
3. ときどき大きなヨーヨーも飛んでくる。目安は通常80〜85%、大きめ15〜20%。大きいものは少し遅くし、子どもが避ける時間を確保する。
4. 操作は**浴衣の子を指で左右に動かす**。タッチ操作最優先。必要ならPCの左右矢印キーにも対応。
5. おためし版として30秒、ライフ3つを初期値にし、定数で容易に調節可能にする。最初は少なめ、中盤以降に出現頻度を少し上げる。失敗→すぐ再挑戦、30秒完走→クリア演出を用意。
6. **当たり判定は画像の見た目に合わせて少し甘め**。画面外やプレイヤーが移動できない範囲から突然衝突するような理不尽な配置を避ける。プレイヤーが左右移動のみでも避けられる軌道を優先し、横・下方向からの出現は画面下部の当たり判定帯や予兆表示を考慮して調整する。
7. 同じ種類の連続出現ばかりにならないようにする。ゲーム内で6種類全てが使われることを検証する。
8. パフォーマンス重視：requestAnimationFrame、画面外オブジェクトの削除、描画数の上限を設け、スマホで軽快に動かす。色味・エフェクトを付け足しすぎず、キャラクターが見やすい状態を保つ。
