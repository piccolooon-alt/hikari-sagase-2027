# 赤の光・ヨーヨーよけ改修素材

- `assets/yoyos/yoyo_red.png` 赤
- `assets/yoyos/yoyo_blue.png` 青
- `assets/yoyos/yoyo_yellow.png` 黄
- `assets/yoyos/yoyo_green.png` 緑
- `assets/yoyos/yoyo_purple.png` 紫
- `assets/yoyos/yoyo_pink.png` 桃

ヨーヨー6点は、個別の背景透過PNGで、表示サイズの差が不自然にならないよう600px角の透明キャンバスに収めています。元のイラストの模様や紐をできる限り残しています。

今回のZIPは改修素材とプロンプトです。ゲーム自体の完成コードや、公開済みのサイト全体は含めていません。CodexはGitHub上の現行コードを読み、追加してください。
