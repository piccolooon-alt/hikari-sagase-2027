# 光をさがせ！ in 水袋公園 by 寺子屋すずらん

2027年8月7日（土）・8日（日）の夏まつりに向けた、**GitHub Pages 公開確認版**です。承認済みの試作品の見た目と操作を引き継ぎ、添付された画像・BGMをそのまま使っています。

**本番ゲームではありません。実際のQR読み取り、参加者間の共有、受付スクリーンとの連動は未実装です。** 写真アップロード、GPS取得、外部データベース接続はありません。

## ローカルで開く

ビルドや本番用パッケージのインストールは不要です。Python 3でリポジトリのルートを配信します。

```sh
cd hikari-sagase-2027
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーでポート8000の `index.html` を開いてください。受付画面は `projector.html` です。`file:` で直接開く方法ではなく、HTTPサーバー経由で確認します。

- 1日目：`index.html?day=1`
- 2日目：`index.html?day=2`
- 赤の素材確認：`index.html#red`
- ヒント帳：`index.html#hintbook`（ヒント帳内の日付切り替えでも確認できます）

投稿や発見状況は日別に分けた `localStorage` のデモ記録です。同じスマホでも別のブラウザーでは共有されず、別のスマホや受付画面にも送信されません。保存が制限されるブラウザーでは、画面を閉じると入力内容が失われる場合があります。本名や個人情報を入力しないでください。

## GitHub Pagesで公開する

公開対象は **`piccolooon-alt/hikari-sagase-2027` だけ**です。過去のゲーム用リポジトリは操作しません。

1. 制作用ブランチのPull Requestを確認し、`main` にマージします。
2. このリポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** を **main**、フォルダーを **/ (root)** にして **Save** を押します。
5. GitHub側のデプロイ完了を待ち、Pagesに表示されたURLを開きます。

予定URLは次のとおりです。**URLの記載は、公開・到達確認が完了したことを意味しません。**

- スマホ用：`https://piccolooon-alt.github.io/hikari-sagase-2027/`
- 受付用：`https://piccolooon-alt.github.io/hikari-sagase-2027/projector.html`

GitHub Pagesの有効化や公開範囲は、リポジトリの権限・GitHubプランに応じて管理者が設定してください。CSS・JavaScript・画像・音源は相対パスで参照し、このリポジトリ名のサブパスで配信できます。ビルド処理や外部データベースの設定は不要です。

公開後はAndroid／iPhoneの実機で、起動→はじめ→ホームの背景とボタン、各画面への移動と戻る操作、BGMのON/OFF、文字入力、画面の上下端を確認してください。受付画面は16:9のスクリーンで確認してください。

## 検証

自動確認ではスマホ幅360／390／430px、画面遷移、日別の端末内記録、BGM、素材読み込み、受付画面のカウントを対象にします。エミュレーションは実機の音声出力やブラウザー固有の挙動を保証するものではありません。

```sh
npm ci
# Chromiumをインストールしていない環境で初回のみ実行
npx playwright install chromium
npm test
```

既存の `/usr/bin/chromium` があればそれを使います。別の実行ファイルは `CHROMIUM_PATH` で指定できます。テスト用パッケージは開発時だけ必要で、サイトのビルド・公開には不要です。テストは `/hikari-sagase-2027/` のサブパスで一時サーバーを起動し、終了時に停止します。

今回、Chromium 154で**15シナリオすべて成功**しました。Android／iPhone相当のUA・タッチ設定で幅360／390／430px、受付画面1920×1080とスマホ幅を確認しました。実行結果・スクリーンショットは `tests/artifacts/` に出力します。レビュー用の画面と詳しい結果は [検証記録](docs/VALIDATION.md) にあります。

実際のSafari／WebKitエンジン・Android／iPhone実機・GitHub Pages公開後の確認は未実施です。このクラウド環境ではWebKit配布先への通信がHTTP403で拒否されました。iPhone相当のUA設定も、今回の実行エンジンはChromiumです。
